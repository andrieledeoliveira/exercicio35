
# Exercício de Vetores em Java

## Sobre o projeto

Este projeto apresenta um exercício básico de algoritmos e programação em Java, utilizando vetores para armazenar números inteiros.

O programa solicita ao usuário 20 números inteiros, calcula a soma dos valores armazenados e apresenta a média aritmética dos números informados.

## Tecnologias utilizadas

Java
Scanner para entrada de dados pelo teclado.
Vetores (arrays) para armazenar os números.
Estruturas de repetição for para leitura e processamento dos valores.

## Funcionamento

1. Solicita ao usuário a digitação de 20 números inteiros.
2. Armazena os valores em um vetor.
3. Calcula a soma de todos os números informados.
4. Calcula a média aritmética dos valores.
5. Exibe a soma e a média na tela.

## Objetivo

Praticar conceitos fundamentais de programação em Java, incluindo declaração de variáveis, entrada de dados, vetores, estruturas de repetição e operações matemáticas.
